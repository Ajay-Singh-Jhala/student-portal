# Student Portal

A C++ console app simulating a basic student portal: login, profile, dashboard, settings.

## Prerequisites

- g++ (C++17 or later)
- Git

## Installation

1. Clone this repository
2. cd into the project folder

## Build Instructions

```bash
g++ -std=c++17 src/*.cpp -o student_portal
```

## Usage

```bash
./student_portal
```

## Project Structure

- src/ - source files per module
- README.md - this file
